# EXTENSION: Custom Practice voice cloning (modules/voice_clone.py)

# Nothing new is REQUIRED for the reliable tier of voice cloning (real
# recorded-voice reuse, works for both languages) -- it only needs the
# sqlite3/os/json already used everywhere else in this project.
#
# The OPTIONAL tier -- true zero-shot neural voice cloning of arbitrary
# new English text (Coqui TTS's XTTS-v2 model) -- needs the `TTS`
# package below. It is commented out by default because it is a large,
# heavy install (pulls in PyTorch and downloads a multi-GB model the
# first time it runs) and Kannada isn't supported by it at all (see
# voice_clone.py's module docstring) -- for many setups, especially a
# typical home/school laptop, the reliable recorded-voice tier alone is
# both simpler and sufficient. Uncomment the line below only if you
# specifically want true English voice-cloned synthesis in addition to
# real recorded playback; the app checks for this at runtime and works
# perfectly well without it either way.
# TTS

# RECOMMENDED tier that enables true, arbitrary-text voice cloning for
# BOTH languages (including Kannada, where XTTS above has no support at
# all) -- OpenVoice V2 tone-colour conversion, via the pip-installable
# `openvoice-cli` package (confirmed to install and import cleanly).
# This is what powers the "record 10-15 phrases once, then any typed
# sentence is heard in that voice" enrollment feature in Custom
# Practice. It does NOT teach a model to "speak Kannada" itself; it
# re-voices audio this app's own existing TTS pipeline already
# generates correctly, to sound like the recorded profile (full,
# honest explanation in voice_clone.py, right above _openvoice_clone).
# It's a real install (PyTorch + a one-time ~200MB checkpoint download
# from Hugging Face on first use, then cached locally forever). Without
# it, Custom Practice still works perfectly via real recorded-word/
# sentence playback (tier 1), just without synthesized cloning of
# brand-new typed text.
openvoice-cli

# OPTIONAL, PAID CLOUD tier (modules/sarvam_voice.py) -- Sarvam AI's
# hosted voice-cloning API. Tried BEFORE OpenVoice above (see
# voice_clone.py's clone_synthesize) because it's simpler and more
# reliable once configured: one clone -> one voice_id -> reused for
# ANY typed sentence, in EITHER English or Kannada, with no local model
# to download or load. STATED HONESTLY: this is a commercial API (not
# free/open-source like OpenVoice), it needs internet on every
# generated sentence, and it uploads the profile's recorded reference
# clip + every generated sentence's text to Sarvam's servers -- worth
# knowing before using it with real family recordings, not just a demo.
# To enable it:
#   1. pip install sarvamai
#   2. Get an API key from https://www.sarvam.ai
#   3. Set it as an environment variable (never hard-code it in source
#      or commit it to git) -- in PowerShell:
#        $env:SARVAM_API_KEY="your-key-here"
# Without SARVAM_API_KEY set, this tier is silently skipped (printing
# one explanatory line) and the app falls straight through to
# OpenVoice, then to real recorded playback -- nothing else breaks.
sarvamai
