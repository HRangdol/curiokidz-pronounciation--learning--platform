🎤 Clone a whole lesson into a voice

Pick any saved lesson (built-in or uploaded) and an existing voice profile — every line gets cloned in that voice, so a child can listen to the whole lesson read aloud in a familiar voice. This uses ONLY open-source models (XTTS-v2, then OpenVoice V2) — never Sarvam, which is a paid closed-source API and is skipped entirely for this feature.

Don't see the voice you want? Go record one first in Custom Practice — it just needs at least one recording in this language. Tip: cloning one stanza at a time is much faster (a stanza is usually just 3–5 lines) — clone stanza 1 first to check it sounds right, then do the rest. Each stanza you clone is added to what's already playable, nothing is lost.
